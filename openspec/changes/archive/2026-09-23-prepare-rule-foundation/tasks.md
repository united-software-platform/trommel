## 1. Общий обход дерева

- [ ] 1.1 Вынести обход дерева файлов из `internal/docrules` в общий пакет: перечисление по признаку, исключение скрытых и заданных каталогов, учёт непрочитанного; проверка — пакет не зависит ни от одной группы правил
- [ ] 1.2 Перевести десять действующих правил на общий обход; проверка — вердикт по репозиторию совпадает с прежним посимвольно, включая числа просмотренного

## 2. Предмет проверки

- [ ] 2.1 Описать предметы реестром: имя, что поставляется правилу, чем поставляется прогону; проверка — перечень предметов получается из реестра, а не из перечисления в коде прогона
- [ ] 2.2 Реализовать поставку предмета «текст сообщения коммита» правилу; проверка — правило-образец получает текст и возвращает по нему вердикт
- [ ] 2.3 Реализовать поставку предмета «состояние репозитория»; проверка — правило-образец получает имя текущей ветки
- [ ] 2.4 Подтвердить отказ при непоставленном предмете для каждого объявленного предмета; проверка — тесты покрывают все предметы реестра, а не только один

## 3. Область действия правила

- [ ] 3.1 Ввести область действия наряду с предметом: «документ» и «проект»; проверка — правило объявляет область, прогон исполняет правило области «проект» однажды, а не по разу на файл
- [ ] 3.2 Уточнить инвариант `ok` для области «проект» в спецификации `rule-verdict`; проверка — формулировка охватывает обе области и не опирается на число файлов
- [ ] 3.3 Реализовать правило-образец области «проект»; проверка — правило видит содержимое всех документов сразу и сообщает находку с указанием нескольких из них

## 4. Параметры правил

- [ ] 4.1 Реализовать правило-образец, требующее параметра конвенции; проверка — незаданный параметр даёт отказ до прогона, заданный меняет поведение правила
- [ ] 4.2 Описать в `trommel.yaml` конвенции этого репозитория для правила-образца; проверка — прогон по репозиторию использует объявленные конвенции

## 5. Точечный режим прогона

- [ ] 5.1 Реализовать запрос отдельного правила с переданным предметом без обхода проекта; проверка — прогон одного правила по тексту сообщения не открывает ни одного файла проекта
- [ ] 5.2 Измерить время ответа точечного запроса; проверка — измерение выполнено и записано, пригодность для хука оценена по нему, а не предположением
